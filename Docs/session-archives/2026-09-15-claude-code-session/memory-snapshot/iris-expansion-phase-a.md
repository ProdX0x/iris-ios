On 2026-09-12, on `feature/game-expansion`, a design-only phase produced the `Design/` documents (invariants, comfort constraints, difficulty model, twelve concepts, campaign structure) and `GAME_EXPANSION_DESIGN_REPORT.md`. Finalists awaiting the user's judgement: Souffles (drifting mist the gaze deflects, active guarding), Braises (cold lueurs fed by short looks that also repel them), Rendez-vous (twin lueurs that are each other's goal, a respiration chapter), Phares (irises that open and close slowly and exhale when closed). Reserve: Ancres, Nuée, Élan, Accord. Rejected: Ombres, Pénombre, Regard calme, Carrefour. Proposed order: I II III IV, Rendez-vous, Veilleuses, Souffles, Phares, Braises, Clairvoyance.

**Why:** the user wants to judge concepts on paper before any night of implementation; the existing six chapters are a working base, not the final definition; the core mechanic is sacred.

**How to apply:** do not create chapter 7+ levels, new mechanics or StoreKit until the user picks finalists (phase B); each approved concept starts with a two-level prototype played on iPhone. Phase B1 (2026-09-12) built the Braises prototype on branch `prototype/braises` (chapter 0 "P", DEBUG only, levels `0-1`/`0-2`, launched from Settings → prototypes; `BRAISES_PROTOTYPE_REPORT.md`): the human test of 416feb9 validated A (frozen: sleep, wake, drift, flare, wider reach when flaring) and found B indistinguishable from A; B1.1 on branch `prototype/braises-b-rework` reworked B by level design only (braise sleeping 120 pt above iris 1, wake before the lueur settles or chase it) ; the B1.1 human test still found B's purpose unclear, so B1.2 (branch `prototype/braises-b-ux-audio`) states the rule on the intro card and concludes by analysis that B is a deterministic optimal rule (wake early), not an arbitrage; B1.2 also split the single sound switch into Effets sonores (default on) and Ambiance sonore (default off, the drone was judged dull on device), with a migration that never re-enables sound (audio then validated by the user). B1.3 (branch `prototype/braises-b-final-diagnostic`) measured that the late-wake consequence is a self-healing 60 pt / 1.7 s blip, absent when the gaze sits above the braise: Braises B is REJECTED in its current form, no B1.4 allowed; a DEBUG lab readout exists for chapter-0 levels. Never touch A's tuning (`BraiseDefinition.prototype`) or the braise engine without an explicit request; never merge into the campaign without a verdict. Respect `Design/PLAYER_COMFORT_CONSTRAINTS.md` (mandatory gaze targets ≥ 0.18 of short side, no gaze-velocity mechanics, no corner irises reached by pushing, respirations). See [[iris-human-validation]] and [[iris-project-setup]].

**Superseded (13 Sept 2026):** the user then asked for direct production; Rendez-vous became chapter VII jumelles, Souffles chapter VIII, Braises chapter XI; Phares was dropped in production (no real decision, only waiting) and Échos, Gouffres and Constellation were added. See [[iris-full-expansion]].
